# Create Demand Dataset

Raw data:

| pickup_time | zone |
| ----------- | ---- |
| 10:01       | 161  |
| 10:05       | 161  |
| 10:15       | 161  |

ML cannot learn from raw trips.

Convert into:

| hour  | zone | demand |
| ----- | ---- | ------ |
| 10:00 | 161  | 3      |

---

Create hourly bucket:

```python
df['hour'] = (
    df['tpep_pickup_datetime']
    .dt.floor('h')
)
```

Aggregate:

```python
hourly_df = (
    df.groupby(
        ['hour','PULocationID']
    )
    .size()
    .reset_index(name='demand')
)
```

This is your forecasting dataset.

---

## Lag Features

Most important feature.

Previous demand predicts future demand.

Example:

| Hour | Demand |
| ---- | ------ |
| 10   | 100    |
| 11   | 120    |
| 12   | ?      |

Create:

```python
lag_1
lag_2
lag_24
```

Meaning:

| Feature | Meaning             |
| ------- | ------------------- |
| lag_1   | Previous hour       |
| lag_24  | Same hour yesterday |

Example:

```python
hourly_df['lag_1'] = (
    hourly_df.groupby(
        'PULocationID'
    )['demand']
    .shift(1)
)
```

---

## Rolling Features

Create:

```python
rolling_mean_3
rolling_mean_24
```

Example:

```python
hourly_df['rolling_24'] = (
    hourly_df.groupby(
        'PULocationID'
    )['demand']
    .transform(
        lambda x:
        x.shift(1)
         .rolling(24)
         .mean()
    )
)
```

Reason:

Capture recent trend.

---

# Target Variable

hourly_df['target'] = (

# Train Test Split

Never:

```python
train_test_split()
```

for time series.

Wrong.

---

Correct:

Suppose January has 31 days.

```text
1–25 Jan   → Train

26–28 Jan  → Validation

29–31 Jan  → Test
```

Chronological order must remain.
