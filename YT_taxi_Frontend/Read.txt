🚖 NYC Taxi Demand Forecasting & Analytics System
📌 Project Overview

This project is an end-to-end Machine Learning application built using FastAPI and Streamlit to analyze NYC Yellow Taxi data. The system provides multiple intelligent services to help understand taxi demand patterns and support driver decision-making.

The application consists of four major use cases:

Taxi Demand Forecasting
Trip Duration Prediction
Pickup Hotspot Detection
Optimal Driver Position Recommendation
🚀 Application Flow

The application follows this architecture:

User (Streamlit UI)
        ↓
FastAPI Endpoints (main.py)
        ↓
Business Logic (services/)
        ↓
ML Models / Data Processing
        ↓
Response to User
Step-by-Step Flow
1. User Interaction (Streamlit)
Users interact with the web interface built using Streamlit.
Each page collects input from the user.
Input data is sent to FastAPI through HTTP requests.

Example:

Streamlit Form
    ↓
requests.post(...)
    ↓
FastAPI API Endpoint
2. API Layer (FastAPI)

main.py acts as the entry point for backend services.

Responsibilities:

Defines API endpoints.
Validates incoming requests using Pydantic schemas.
Calls the appropriate service functions.
Returns prediction results.

Available Endpoints:

POST /forecast
POST /predict-duration
POST /hotspots
POST /recommend-driver-position
3. Request Validation (schemas/)

Schemas define the expected input structure.

Responsibilities:

Validate user inputs.
Ensure correct data types.
Prevent invalid requests.

Example:

class TripRequest(BaseModel):
    passenger_count: int
    trip_distance: float
    pickup_hour: int
    PULocationID: int
    DOLocationID: int
4. Business Logic Layer (services/)

Services contain the core logic of the application.

Responsibilities:

Feature engineering.
Data preprocessing.
Calling trained ML models.
Computing recommendations.

This layer separates application logic from API code, making the application easier to maintain and scale.

📊 Use Cases
1. Taxi Demand Forecasting
Purpose

Predict future taxi demand for upcoming time periods.

Inputs
Forecast horizon (number of future periods)
Process
User specifies the number of future periods.
FastAPI receives the request.
Forecasting service loads the trained forecasting model.
The model predicts future taxi demand.
Results are returned to the Streamlit interface.
Output
Forecasted taxi demand values.
2. Trip Duration Prediction
Purpose

Estimate how long a taxi trip is expected to take.

Inputs
Passenger Count
Trip Distance
Pickup Hour
Pickup Location ID
Drop-off Location ID
Process
User enters trip details.
FastAPI validates the request.
Service layer performs feature engineering:
Location Pair
Pickup Month
Pickup Day
Pickup Day of Week
Weekend Indicator
Night Indicator
Rush Hour Indicator
Processed features are passed to the trained XGBoost model.
The model predicts trip duration.
Output
Estimated trip duration in minutes.
3. Pickup Hotspot Detection
Purpose

Identify zones with the highest taxi pickup activity.

Inputs
Number of hotspot zones required (Top N)
Process
User specifies the number of hotspots.
FastAPI forwards the request to the hotspot service.
Historical pickup data is analyzed.
Pickup frequencies are calculated.
Zones are ranked by pickup demand.
Output
List of top pickup hotspot zones.
4. Optimal Driver Position Recommendation
Purpose

Recommend the best zones for drivers to position themselves based on predicted demand and revenue potential.

Inputs
Current Zone
Hour of Day
Day of Week
Maximum Travel Distance
Show Top Zones Option
Process
The system evaluates nearby zones.
Demand potential is estimated for each zone.
Revenue potential is calculated.
A recommendation score is generated by combining demand and revenue factors.
Zones are ranked based on their scores.
The highest-scoring zone is recommended to the driver.
Output
Recommended Zone
Recommendation Score
Top Alternative Zones

▶️ Running the Application
1. Start FastAPI Backend
uvicorn main:app --reload

Backend will run at:

http://127.0.0.1:8000

API documentation:

http://127.0.0.1:8000/docs
2. Start Streamlit Frontend

Open another terminal and run:

streamlit run app.py

Frontend will run at:

http://localhost:8501
🎯 Project Goal

The goal of this project is to build a production-style machine learning system that combines forecasting, trip duration prediction, hotspot analysis, and driver recommendation capabilities to support data-driven decision-making in urban taxi operations.

This system demonstrates how machine learning models can be integrated into real-world applications using FastAPI and Streamlit to provide actionable insights for taxi service management and drivers.
